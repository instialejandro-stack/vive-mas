# Vive Más

Primera version de una plataforma de contenido sobre vida saludable, bienestar, alimentacion, ejercicio y habitos sostenibles.

## Stack

- Next.js con App Router
- React
- TypeScript
- Tailwind CSS

## Ejecutar en local

```bash
npm install
npm run dev
```

Despues abre `http://localhost:3000`.

## Estructura

- `app/`: rutas, SEO y paginas iniciales.
- `components/`: piezas reutilizables de interfaz.
- `data/`: contenido local preparado para menus, habitos, entrenamientos y articulos.
- `public/images/`: assets visuales del proyecto.

No incluye base de datos, login ni pagos. La estructura esta preparada para conectar un CMS o una API cuando el proyecto crezca.
